## المزايا

- 🗺️ **خريطة واضحة** مع 4 أنماط: ليلية، شوارع واضحة، OpenStreetMap، أقمار صناعية.
- 🔎 **بحث عن الأماكن** داخل العراق، مع اختصارات قريبة مني (مستشفى، صيدلية، وقود، مطعم...).
- 🧭 **مسارات حقيقية** مع بدائل (الأسرع / الأقصر / بديل) ووقت الوصول والمسافة.
- 🔊 **ملاحة خطوة بخطوة** مع إرشاد صوتي بالعربية، السرعة، إعادة حساب المسار تلقائياً عند الخروج عنه.
- ⭐ **المفضلة**: البيت والعمل وأماكن محفوظة، وسجل الوجهات الأخيرة.
- 📣 **البلاغات**: حادث، ازدحام، أعمال طرق، إغلاق، خطر، أخرى — تظهر على الخريطة.
- ⚙️ إعدادات وحساب محلي (إحصائيات الرحلات) وشاشة بداية بهوية سيّار.

كل الخدمات **مجانية وبدون مفاتيح API**: OpenStreetMap / CARTO / Esri للخرائط، Nominatim للبحث، OSRM للمسارات.

## الرفع على GitHub وبناء الـ APK

1. أنشئ مستودعاً جديداً على GitHub باسم `sayyar` (يفضّل Public).
2. فك ضغط الملف، وارفع **محتويات** المجلد إلى **جذر** المستودع (يعني `pubspec.yaml` و`lib` و`assets` و`.github` مباشرة، بدون مجلد إضافي فوقها).
3. افتح تبويب **Actions** وانتظر انتهاء `Build SAYYAR APK` (حوالي 8–12 دقيقة).
4. حمّل الـ APK من أحد مكانين:
   - **Releases** (الأسهل): ملف `Sayyar.apk` مباشرة.
   - **Actions → آخر تشغيل → Artifacts**: `SAYYAR-APK`.
5. ثبّت الـ APK على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

> لتغيير صورة المستودع: **Settings → General → Social preview** وارفع `assets/icon/avatar.png`، وللأفتار الشخصي للحساب/المنظمة استخدم نفس الصورة.

## ملاحظات صريحة (مهمة)

- **لا توجد بيانات ازدحام مباشر**: لا يوجد مصدر مجاني موثوق لازدحام العراق، لذلك المسارات تعتمد على أوقات القيادة المعتادة وليس الازدحام الحالي.
- **البلاغات محلية حالياً**: تُحفظ على جهاز المستخدم فقط. لمشاركتها بين المستخدمين (مثل Waze) تحتاج خادماً خلفياً (Supabase / Firebase) — الكود مهيّأ لإضافته لاحقاً عبر دوال `addReport` و`removeReport`.
- **الخريطة ثنائية الأبعاد**: الخرائط المجانية لا تدعم المباني ثلاثية الأبعاد.
- **حدود الاستخدام**: خوادم OSRM وNominatim وCARTO العامة مجانية للاستخدام الخفيف. إذا كبر عدد المستخدمين، استضف خادم مسارات وبحث خاص بك أو استخدم مزوّداً مدفوعاً. صور الأقمار الصناعية (Esri) لها شروط استخدام خاصة قبل أي نشر تجاري.
- الإرشاد الصوتي يحتاج أن يكون على هاتفك **محرك نطق عربي** (Google Text-to-Speech مع تنزيل اللغة العربية).
- التوقيع: الـ APK الناتج موقّع بمفتاح تجريبي (debug) ويصلح للتثبيت المباشر. للنشر على Google Play تحتاج مفتاح توقيع خاص.
